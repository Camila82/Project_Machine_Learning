Data Engineering

Transformations, Feature Engineering, and Preparation for Machine Learning.

1. Data Cleaning & Null Handling

The initial dataset consisted of 1,000 raw acoustic records. A rigorous data quality assessment revealed 0 missing values across all columns, indicating high-fidelity sensor captures.

  • Format Standardization: Datetime columns were parsed, and Latin character encodings (ISO-8859-1) were corrected to ensure seamless processing.
  • Anomaly Removal: Duplicate ID_Registro entries were verified and confirmed to be zero.

2. Encoding & Normalization

Machine Learning algorithms require numerical inputs. Categorical variables were structurally transformed.

  • Label Encoding: Categorical features (Tipo_Zona, Fuente_Principal_Ruido) were mapped to integer hierarchies using Scikit-Learn's LabelEncoder.
  • Target Ordinal Mapping: The target variable (Clasificacion_Normativa) was mapped ordinally: Bajo (0) → Moderado (1) → Alto (2) → Crítico (3).
  • Min-Max Scaling: Continuous variables like vehicular flow and speeds were scaled between [0,1] to ensure neural network and distance-based model stability.

3. Feature Engineering

Raw acoustic data is insufficient to capture complex urban dynamics. Based on Colombian traffic laws and acoustic normatives, 7 new synthetic features were engineered to improve model predictive power.

Time_Band

Categorized 24-hour cycles into 4 strategic bands (Early Morning, Morning, Afternoon, Night) aligning with the MADS regulations.

Is_Peak_Hour

Binary flag identifying standard Colombian rush hours (07:00-09:00 and 17:00-19:00) where mobility congestion peaks.

Congestion_Index

A weighted composite metric combining public transport saturation (60%) and the raw mobility index (40%).

Exceeds_Limit

Binary target flag indicating if the specific zone surpassed the legal decibel threshold established by Resolution 627/2006.

Noise_Speed_Ratio

The ratio of generated dB to average vehicle speed, isolating noise generated by engine idling vs. high-speed transit.

Temporal Seasonality

Extraction of Month and Quarter variables to allow tree-based algorithms to detect seasonal noise spikes.
